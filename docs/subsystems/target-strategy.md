# 目标分数策略

试卷详情的 AI 作答可开启目标分数模拟：输入目标分数、容差、可备考时间、考试分钟、检查预留和能力自评。
请求与冻结计划分别存于 `paper_jobs.strategy_request_json` 与 `strategy_plan_json`；未开启时为普通作答。

## 规划

分题完成后、生成答案前执行。分析读取题面、知识目录与严格配对且校验和一致的 Source Booklet，不读取
Mark Scheme 或 Examiner Report，也不向分析模型提供目标字段。共享知识与前置学习只计一次，熟练度练习
单独计入；学习与考试两个预算同时约束，以预算使用比例等权选择推荐路径，并展示少学与快答候选。搜索
上限 4096 个状态，触顶时标为近似推荐。

## 计分语义 `target-score-v2`

- 规划分数指正确完成选定内容时的得分；完整小题使用原题印刷分值。
- 部分作答描述有明确停止点 `stop_before` 的步骤或论证；路径总上界不超过目标加容差，推荐方案总下界
  不低于目标减容差。
- 文字论述类部分作答（`text / essay / extended_response`）使用 0 至该小题满分的保守区间参与筛选，
  保留模型点估计。
- 能力自评只影响学习、练习与作答成本，不折扣分值。没有学生画像和耗时校准，不预测学生个人成绩。

## 执行

共享执行编译器把选定小题、`stop_before`、每题考试分钟、本题知识与前置传给答题 Agent。只支持同一
大题内向前依赖。策略内无图时禁用整题视觉回退；输出校验拒绝已舍弃子题标题。

策略答案在引用整理后做一次独立范围复核：输入题面、选定范围、最终文字与矢量图，不提供目标、分值
估计、评分材料或求解轨迹。`violation`、`uncertain`、复核不可用或无检索证据时该题不能完成；位图内容
保守返回 `uncertain`。复核在题目总时限内预留至多 60 秒，无供应商重试，结论与最多三条证据写入审计
事件。普通作答不执行此复核。

计划在生成答案前持久化；重试复用冻结计划并核对输入摘要；已完成策略题禁止单题重做。缺少停止边界的
部分方案提示新建任务，不静默重规划。主动留空的题技术状态为 `completed`，业务标记
`skipped_by_strategy=true`。实际分数仍由评分链路形成。

## 实验脚本

`scripts/validate_target_strategy.py`、`validate_strategy_runtime.py`、`validate_strategy_scope.py` 需显式
`--live` 才调用模型，输出目录必须全新。
