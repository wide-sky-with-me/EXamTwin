# 原卷作答 PDF 导出

来源核对通过的 PDF 作答任务结束后，可从作答记录导出“原卷作答 PDF”。导出只复用已保存的正文、公式、
图片和图形，不调用模型，不改写原件、结构化答案、引用或评分记录。

## 后端布局接口

`GET /api/v1/papers/jobs/{job_id}/answer-pdf/layout`（`assessment/paper_export.py`）校验科目与任务归属，
按物理页识别能归属到题号或子问的答题横线组，排除原文与图形占用区，返回原件 SHA-256 与显示坐标。
扫描卷、选项、填空和表格等没有可靠依据的区域不自动定位。

## 前端编辑与生成

`PaperAnswerPdf` 按需加载锁定版本的 `pdf-lib` 与 `html-to-image`：

1. 冻结本次答案快照；用户选择子问与原卷页，采用建议区域、框选或输入位置。
2. 确认区域不遮挡题干或原图后生成实际 PDF 预览，再下载。
3. 正文与公式按固定清晰字号排入区域；已校准图形沿原页坐标叠绘，普通图形随子问排版。
4. 空间不足时原区标注 `See PDF p. N` 并追加带题号与原卷页码的续答页。

原卷页面内容保留，新增答案为透明高清图像层，不是可选择文本。位置调整只用于本次导出，不跨窗口保存。

## 门禁

生成前检查原件哈希、来源页、页面旋转与裁剪坐标、区域越界与重叠、原图叠绘冲突、公式横向溢出、图片
加载失败与空白图形。分页只在渲染后的空白行处切分；单段超过一页且无法分割时停止导出。部分完成的
任务只写已完成答案，附未完成题目清单，文件名含 `partial`；策略主动留空的题不进入未完成清单。

不支持：自动圈选选项、逐单元格填表、按空间重写答案。
