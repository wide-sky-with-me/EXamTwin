# 列表筛选与分页视觉优化

## 做了什么

科目管理、试卷管理和试卷作答记录统一换用 Radix Themes 搜索、筛选和分页控件；移除筛选框上方重复小标签，补齐聚焦/展开高亮。科目分页改为页面底部的精简底栏。

## 改了哪些

- `frontend/src/components/ui/ListControls.tsx` — 使用 Radix TextField、Select、Button 与 IconButton 重做共享控件。
- `frontend/src/pages/SubjectManagement.tsx` — 状态和考试局接入共享下拉。
- `frontend/src/pages/PaperManagement.tsx` — 年份、考季和单元接入共享下拉。
- `frontend/src/components/PaperJobHistory.tsx` — 状态、单元和时间接入共享下拉。
- `frontend/src/styles.css` — 重做焦点、菜单、响应式工具栏和底部分页布局。

## 怎么验证的

前端 116 项测试、ESLint、TypeScript 和 Vite 生产构建通过。真实浏览器逐页检查三个模块的 1440px 与 390px 布局、下拉展开和搜索聚焦，均无水平溢出。
