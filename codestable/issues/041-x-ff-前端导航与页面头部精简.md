# 前端导航、品牌图标与页面头部精简

## 做了什么

让桌面侧边栏可以折叠并记住状态，补充统一的 ExamTwin 品牌图标，同时移除多个功能页头部的重复说明文字。

## 改了哪些

- `frontend/src/App.tsx` / `frontend/src/styles.css` — 新增 256px/76px 双态侧边栏、可访问的展开/收起按钮、平滑过渡和本地状态记忆。
- `frontend/public/examtwin-icon.svg` / `frontend/index.html` — 新增渐变双页勾选品牌图标，注册 favicon、触屏图标和主题色，并用于桌面/移动端品牌入口。
- `frontend/src/pages/SubjectManagement.tsx`、`PaperManagement.tsx`、`Reviews.tsx`、`SubjectOverview.tsx`、`PaperAnswering.tsx` — 删除页头 eyebrow 和大段解释，只保留标题、必要科目上下文及主操作。
- `frontend/src/AppNavigation.test.tsx` — 覆盖展开/折叠呈现、导航和可访问操作。
- `frontend/src/pages/PaperManagement.tsx` / `frontend/src/styles.css` — 修复试卷详情图标基线不一致；将资料绑定改为结构化卡片列表，统一角色图标、状态、文件名、页数和进入指示，并补充移动端收敛样式。
- `frontend/src/pages/PaperManagement.test.tsx` — 锁定资料绑定列表的图标、内容与元数据分区结构。
- `frontend/src/pages/PaperManagement.tsx` / `frontend/src/styles.css` — 在试卷卡片逐项展示 Question Paper、Mark Scheme、Source Booklet 的实时解析状态和完成比例；待解析卡片提供一键入队，沿用串行转换队列并实时反映排队、解析、失败与完成状态。
- `frontend/src/pages/PaperManagement.test.tsx` — 覆盖卡片一键解析三份绑定资料、队列顺序、实时状态和不误触详情导航。
