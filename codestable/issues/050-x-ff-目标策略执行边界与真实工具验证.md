## 做了什么

按用户“继续增强并交另一个 Agent 评判”的授权，补强部分作答停止、保守得分区间和实际
工具执行，继续验证数学与经济。独立 Agent 分别做代码／范围审查及不知道目标的答卷盲评。

## 改了哪些

- 新增共享策略执行编译器，Worker 和真实实验传递相同的小题范围、stop_before、每题考试
  分钟、本题知识及前置。部分方案必须明确停止边界，旧 partial 缺失时提示新建任务；UI
  展示停止点，同步 OpenAPI。正常题号引用不再被跳题标题检查误拦。
- 策略可达判断增加 lower 容差约束。真实经济反例表明单政策答案可得较高等级分，文字
  论述型 partial 因而使用 0–原小题满分保守区间，保留模型点估计和原分析，避免虚假封顶。
- 最终文字及矢量图增加不读取目标／估分／MS／求解轨迹的独立范围复核，记录解释与短
  证据。不确定、违规、复核不可用、位图无法检查及无检索证据时拒绝完成；在最终引用整理
  后复核，普通答题不增加该调用，题目总时限内预留至多 60 秒。
- 真实经济验证暴露结构化终答超时后 fallback 与子题校验契约不一致，统一所有终答／修复
  提示的子题 JSON 形状，涵盖单个 `.1`。新增同故障的离线恢复测试。
- 增加生产 Runtime／计算／绘图／原题视觉／精确 IN 工具实验及四个合成对抗样例脚本，
  支持中断后保留并复用首次完成结果。本地适配器显式使用 local 存储，记录逐事件及来源。

  BasedPyright、架构、OpenAPI／类型、ESLint、TypeScript／Vite、差异检查通过。
