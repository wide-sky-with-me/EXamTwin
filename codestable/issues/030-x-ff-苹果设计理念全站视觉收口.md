# 苹果设计理念全站视觉收口

## 做了什么

逐页核验并修正科目管理、试卷管理、试卷作答、答案评分和复核队列的桌面与窄屏视觉。全站改为内容优先的克制层级：减少投影、装饰边框和空壳面板，以留白、细分隔线、单一蓝色强调和清晰状态表达结构；保留弹窗、危险操作和真实交互控件所需边界。

## 改了哪些

- `frontend/src/styles.css` — 收敛全局投影和卡片装饰，重做科目卡片、试卷统计、列表筛选/分页、评分步骤与响应式布局。
- `frontend/src/pages/Reviews.tsx` — 空队列隐藏无效复核工具栏，改为直接空状态。
- `frontend/src/pages/PaperManagement.tsx` — 无试卷时隐藏全零归档统计。
- `frontend/src/pages/SubjectManagement.tsx` — 科目资料入口使用统一次级按钮样式。
- `codestable/epics/002-o-科目与考试工作流重构/spec.md` — 同步视觉原则、实机验证证据与五入口导航事实。

## 怎么验证的

真实 Chromium 逐页检查五个入口的 1440px 桌面布局与 390px 窄屏布局；科目、试卷、作答、评分和复核页面均无水平溢出，四步评分进度在窄屏同屏可见。前端 16 个 Vitest 文件 / 116 项测试、ESLint、TypeScript 与 Vite 生产构建全部通过。
