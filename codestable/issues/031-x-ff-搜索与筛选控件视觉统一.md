# 搜索与筛选控件视觉统一

## 做了什么

参考 Apple HIG 与 Carbon Search 的页内搜索范式，重做科目、试卷和作答记录共用的搜索筛选栏。搜索改为输入后 220ms 自动更新，Enter 仍可立即执行；移除独立深色搜索按钮，搜索框、筛选下拉、重置与刷新统一为轻量工具栏。修正搜索文字、占位文字和图标的水平/垂直对齐。

## 改了哪些

- `frontend/src/components/ui/ListControls.tsx` — 新增防抖即时搜索，补齐输入语义，移除独立搜索按钮并保留 Enter 提交。
- `frontend/src/pages/SubjectManagement.tsx` — 科目搜索接入即时搜索。
- `frontend/src/pages/PaperManagement.tsx` — 试卷搜索接入即时搜索。
- `frontend/src/components/PaperJobHistory.tsx` — 作答记录搜索接入即时搜索。
- `frontend/src/styles.css` — 统一 44px 控件高度、浅灰表面、圆角、焦点态、图标动作及 390px 折行；精确对齐输入文字和搜索图标。
- 对应 3 个测试文件更新为即时搜索行为断言。

## 怎么验证的

真实 Chromium 验证 1440px 输入 `Mathematics` 后自动只保留数学科目，页面无独立搜索按钮且无水平溢出；390px 科目与试卷筛选栏无水平溢出，搜索输入、占位文字和图标几何中心一致。前端 16 个 Vitest 文件 / 116 项测试、ESLint、TypeScript 与 Vite 生产构建全部通过。
