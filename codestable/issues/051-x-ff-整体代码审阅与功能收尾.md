## 做了什么

按用户要求安排 3 个 Agent 审阅整体代码主要链路，并按此前“完成功能、收尾”的授权修复。
范围包括后端 API / 科目隔离 / 任务持久化与恢复 / 对象存储 / 迁移，策略与 Agent 执行 /
检索隔离 / 评分，以及实际前端入口 / 状态 / 原卷 PDF。主 Agent 负责交叉核实、入口后端
接入、集成检查和收尾。不是逐行证明所有代码没有缺陷，也没有执行在线迁移、部署或模型调用。

去重确认 8 项：4 项 P1，4 项 P2。均已修复并加入相应回归。未发现有证据支持的新 PDF
导出阻断项；继续保留手动确认位置、来源校验与导出前渲染检查。
