# 试卷与作答科目入口调整

## 做了什么

将试卷管理改为按科目数据卡片进入，把新增试卷放进所选科目的内容工作区；将试卷作答的科目选择并入作答记录筛选，并统一可点击元素的鼠标指针。

## 改了哪些

- `frontend/src/pages/PaperManagement.tsx`：移除页头科目下拉；新增与科目管理一致的科目卡片入口、当前科目工作区标题；新增试卷只在进入科目后出现。
- `frontend/src/pages/PaperAnswering.tsx`：移除作答记录上方独立科目选择，把所有科目交给记录组件筛选。
- `frontend/src/components/PaperJobHistory.tsx`：在记录筛选栏新增科目筛选；切换科目时清空单元筛选并保持请求级科目隔离。
- `frontend/src/styles.css`：补充试卷科目卡片、所选状态和工作区布局；未禁用按钮、链接、下拉及可点击角色统一使用 pointer 光标。
- `frontend/src/pages/PaperManagement.test.tsx`、`frontend/src/components/PaperJobHistory.test.tsx`：更新卡片入口测试，并覆盖记录内科目筛选回调。

## 验证

实机确认 1440px 试卷管理有 2 个科目数据卡片、无旧科目下拉，新增试卷位于卡片下方且所有按钮为 pointer；390px 试卷管理和作答记录均无水平溢出。作答记录科目筛选位于记录筛选栏内，旧 `.records-toolbar` 不存在。前端 16 个 Vitest 文件 / 116 项测试、ESLint、TypeScript 与 Vite 生产构建全部通过。
