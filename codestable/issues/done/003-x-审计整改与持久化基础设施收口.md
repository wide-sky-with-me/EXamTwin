# 审计整改与持久化基础设施收口

## 目标

消除当前审计确认的高风险边界：上传请求必须有流式容量限制，时间字段使用数据库时间语义，
资料身份和配对失败可见且可治理，私有基础设施不暴露到 LAN；上传试卷、派生页图、解析缓存
和答案图片通过统一对象存储与保留策略管理，新科目前端不再复制后端单元清单。

## 范围

- 包含：Compose 监听边界；上传流式限额；API 错误契约；TIMESTAMPTZ 迁移；资料逻辑身份、
  版本与配对诊断；S3 兼容对象存储 Port、SeaweedFS、本地迁移和 GC；SubjectPack 元数据接口；
  已确认的低风险并发与提示收口。
- 不包含：声称恢复不存在的旧 Git 历史；对外多用户账号系统；改变模型、RAG 排名、评分权威或
  重新生成已购买资料。经用户在 2026-08-03 明确授权，以当前脱敏快照建立新的初始历史。

## 归属

- 独立 issue；结构原则继承 `002-o-代码结构与模块边界收口.md`，证据身份边界继承
  `001-o-整卷证据作答与细粒度知识图谱.md`。
- 相关 spec：`codestable/spec/index.md`。

## 初始审计问题

- 原 `.git` 为空且旧历史无法恢复；当前按用户授权把现有工程作为新的初始快照，不宣称包含旧历史。
- API 上传先整读内存再检查 25 MB；Provider 异常文本直接回显。
- PostgreSQL/Qdrant 端口监听所有地址；API 本身当前仅监听 loopback。
- 29 个时间字段仍为 Text，租约领取与时间排序依赖 ISO 字符串格式一致。
- 205 份考试类资料中 68 份没有 pair_key；文档 ID 随路径变化，下游引用不稳定。
- 文件字节虽有安全路径封装，但对象元数据、保留期、删除状态与对账没有统一所有者。
- 前端硬编码数学单元；长卷切分静默截断 100000 字符。

## 行为保持

- 现有 REST/WebSocket JSON 形状和任务状态机保持兼容；已有任务、证据、答案和文件可继续读。
- 数据库迁移不得丢失既有行；对象迁移必须可断点、可校验、可回滚到只读旧路径。
- 不把认证、对象存储或迁移失败伪装成健康；外部错误只对客户端返回稳定错误码。

## 质量目标

- 信息安全性：默认 Compose 不向 LAN 暴露 PostgreSQL/Qdrant；内部异常和供应商响应不回显。
- 可靠性：时间比较由 TIMESTAMPTZ 保证；上传超过上限时在继续占用内存前终止；文件与数据库
  删除可对账、失败可重试。
- 可维护性：资料身份、对象生命周期和科目元数据各有一个权威所有者，前端和业务服务不复制规则。
- 兼容性：既有数据库和本地文件平滑迁移，测试可使用本地对象存储替身，生产使用 S3 兼容实现。
- 交互能力：1024px 视口不出现整页横向滚动；错误在所有页面可见；评分风险和可执行恢复动作不隐藏；
  全屏图形支持键盘完整进出。
- 可靠性：基础设施状态按组件探测；实时进度断线重连有上限且不丢后台任务；部分失败不冒充全部完成。

## 实现设计

1. 先修监听、流式上传和错误边界，建立低风险保护层。
2. 迁移所有时间列并用真实 PostgreSQL 验证租约领取、恢复和排序。
3. 将文档逻辑身份、内容版本、位置和配对诊断拆开；扫描输出完整性指标和失败原因。
4. 建立 ObjectStore 深接口与对象元数据/GC；SeaweedFS 作为 Docker S3 实现，旧本地文件按
   校验和迁移，不让业务模块理解 bucket/path 细节。
5. 发布活动 SubjectPack 元数据，前端动态渲染单元；收口视觉提示、长卷切分和阻塞调用。
6. 收口前端状态真实性、响应式与可访问性；后端 health 分别探测 PostgreSQL、Qdrant 和对象存储，
   评分与复核页完整消费既有证据/改分契约，整卷页只把成功完成量映射为完成进度。

### 前端响应式与状态目标

```text
> 1100px   [固定侧栏] [双栏表单 / 结果，宽内容工作区]
901–1100px [固定侧栏] [表单、进度等改为单栏，不产生整页横向滚动]
<= 900px   [顶部横向导航]
            [所有主面板单栏，弹层占可用视口]
```

- API 可达不等于依赖健康：三项基础设施分别显示，任一不可用时顶栏显示 degraded 并阻止新整卷任务。
- 自动评分结果必须同屏展示 warnings、citations、symbolic checks 与 confidence；复核卡同时提供确认和
  合法范围内改分，复核人由界面输入并写入审计记录。
- `partial_failed` 不显示 100%；WebSocket 有界重连后提供手动恢复，成功任务不长期占用恢复缓存，
  失败题或缺少必需图形产物的题可单题重试。
- 全屏答案图是模态交互：初始焦点、Tab 圈定、Escape 关闭和焦点恢复必须成立；减少动态效果设置生效。
