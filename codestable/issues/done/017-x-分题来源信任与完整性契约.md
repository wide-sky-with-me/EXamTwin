# 收口分题来源信任与结构完整性契约

## 目标

任何进入作答的题目都必须同时满足两条独立约束：内容来自同一份可审计主源，结构完整且与可见
题号、子问、分值一致。视觉复核负责识别真实页面内容；PDF 文本层只能帮助定位和恢复主源完全
缺失的题号，不能与主源逐字段拼接，也不能凭“字符串更长”覆盖可信内容。

## 归属

- 独立 bug issue。
- 相关 spec：`codestable/spec/index.md`。
- 由已关闭的 Q8 快修升格：原修复解决了一个已知样本，但复盘确认来源信任、结构完整性和历史
  数据迁移仍没有形成统一契约。

## 当前证据

- 预期行为：9660 S2 Q8 的题干、四个子题、要求与 14 分都来自原卷可见页 16–18；任何缺失或
  来源冲突在持久化前失败。
- 实际行为：Q8 当前已修复并可正确作答，但 `_merge_split_questions` 的旧设计曾让恢复候选
  参与字段级合并；`_combine_repair_group` 仍以“最长字符串”择优；`requires_visual_context`
  又在多个阶段重复推导，尚无单一权威来源。
- 最小场景：主源候选含正确题干但少一个子问，恢复候选含更长、且遗漏印刷分段定义的题干。
  字段级“择长”会生成一个看似完整、实则跨来源拼接的混合题目。
- 原始证据：历史任务 `9baafb32-205b-47b9-b56f-f4784fe7377d` 将 Q8 持久化为
  `grounded=false` 的缺失答案；修复任务 `5a3302ee-c512-4629-a069-7ef7c3139761` 保留页
  16–18、`(a)`–`(d)` 和 14 分，并完成一次 `grounded=true` 作答。

## 现状如何工作

`PaperWorker` 先把整卷按物理页分块并让视觉模型生成主源 Markdown，再批量分题；若发现未解析
印刷内容，会附加 PDF 文本层恢复候选。当前合并器已改为：同题号主源候选之间合并，恢复候选
只补主源完全缺失的题号。随后 `reconcile_question_source_pages` 用可信 Markdown 对齐来源页，
持久化前的占位符门禁会 fail closed；旧数据在作答阶段若仍含占位符，会强制加载原卷页图。

仍未收口的是：同题号多个主源候选如何确定性合并、视觉模型未输出显式占位符时如何证明结构
完整、`requires_visual_context` 的唯一判定点，以及历史 completed 任务如何识别和替换。

## 影响范围

- 必须修改：`paper_parsing.py` 的页面级可见结构提取与完整性契约；
  `paper_answering.py` 的来源分组、结构合并和 checkpoint 契约；
  `paper_worker.py` 的单次判定、持久化门禁和旧数据迁移入口。
- 需要验证：普通文字题、跨页题、图表/坐标/阴影题、缺页/空 OCR、重复候选、旧 checkpoint、
  Worker 重试、真实 Q8 和至少一个无视觉上下文的普通题。
- 仍待调查：现有 completed 历史任务中，除已知 Q8 外还有多少题违反新契约；在新检查器完成前
  不凭文本启发式猜测数量。

## 质量目标

- 来源信任边界：
  - 目标：一个持久化题目只能声明一个权威主源；恢复候选不得覆盖或逐字段补写已有主源题号。
  - 来源：project spec 与本次可靠性/信息安全风险扫描。
  - 预期证据：冲突来源和恢复覆盖用例在持久化前失败；结果保留来源页与来源种类。
- 结构完整性：
  - 目标：可见题号、子问标签、分值和必需视觉对象与结构化分题逐项守恒；无法证明时 fail
    closed，而不是依赖模型主动写出占位词。
  - 来源：本次可靠性风险扫描。
  - 预期证据：漏子问、漏分值、漏图、跨页截断、空页和重复子题回归。
- 可追溯迁移：
  - 目标：不原地改写历史 completed 记录；按新契约审计后生成替代任务，并记录旧任务到新任务
    的替代关系。
  - 来源：审计与复现约束。
  - 预期证据：幂等审计结果、替代关系和新旧任务可回溯。
- 性能效率：
  - 目标：完整性检查复用分块阶段已有的页级视觉结果，不为每题新增一次云模型调用。
  - 来源：project spec 与性能效率风险扫描。
  - 预期证据：调用次数测试；普通文本题不触发额外视觉复核。

## 根因定位

- 根因链：分块独立产生重叠候选 → 合并器没有显式来源信任等级 → 用字段最长值近似完整性 →
  PDF 文本层缺失印刷数学内容时，错误候选可能比正确候选更长 → 混合题仍通过持久化。
- 次生根因：完整性依赖占位符和模型自报 `requires_visual_context`，不能检测“模型无声遗漏”；
  同一标志在 parsing、split、store、answer 多阶段重复推导。
- 影响面：所有跨批、跨页、含表格/图形/分段定义或 PDF 文本层不完整的题；历史 completed
  任务不会因代码升级自动重跑。

## 修复方案

采用“来源原子性 + 确定性结构守恒 + 一次性视觉判定”，不再继续加占位词或文本长度启发式。

1. 分块视觉复核同时产出页级清单：可见顶层题号、子问标签、标注分值、视觉对象和物理页。
2. 分题候选携带不可变来源身份、来源等级、输入页范围和结构清单摘要；checkpoint 升级并只复用
   同契约、同输入摘要的结果。
3. 同一题号只在同一主源组内合并；只合并按标签可证明互补的子问/要求，不择长覆盖 stem。
   同标签内容冲突、总分不守恒或页范围不连续时失败并进入定向视觉复核。
4. 恢复来源只允许创建主源完全缺失的题号；一旦选用，必须回到对应原卷页完成视觉复核后才能
   升格为主源，原始恢复文本只作为定位证据。
5. `requires_visual_context` 在页面结构与最终题目结构对账时计算一次并持久化；后续阶段只消费
   该值，不再各自猜测。
6. 新契约通过后扫描历史 completed 任务；不满足者标记为需替代并创建全新任务，保留原记录。

## 实现设计

### 功能 / 责任怎么分工

- `paper_parsing.py`：定义页级结构清单与题目结构指纹；只做确定性解析、规范化和对账。
- `paper_answering.py`：按来源身份和题号合并候选；执行来源原子性、标签唯一性与分值守恒。
- `paper_worker.py`：编排视觉复核、checkpoint 兼容、最终 fail-closed 门禁和迁移审计。
- Repository：保存结构契约版本、来源摘要、审计状态和替代任务关系；不改写历史答案。

### 请求 / 数据 / 调用怎么走

```text
物理页 → 页级视觉 Markdown + 结构清单
     → 同源分题候选 → 按题号/标签确定性合并
     → 页级清单与题目结构对账
        ├─ 一致：持久化
        └─ 缺失/冲突：定向复核一次 → 仍不一致则 fail closed

PDF 文本层恢复 → 只定位完全缺失题号 → 回原页视觉确认 → 新主源候选
```

### 哪些边界不碰

- 不重做 Answering Agent、RAG、评分器或前端布局。
- 不用 LLM 猜总分、子问标签或缺失公式；不以字符数、Markdown 长度或占位词作为完整性证明。
- 不删除或覆盖历史任务；迁移仅新增审计状态、替代任务和关系。

### 一步步怎么改

1. 先以真实 Q8 与合成的无声遗漏样本固化失败复现，定义页级结构清单和来源身份契约。
2. 改写同源合并器，删除字段级择长；增加冲突、唯一性、页范围和分值守恒门禁。
3. 把恢复路径改为“定位 → 原页视觉确认 → 升格”，禁止恢复文本直接进入已有主源题。
4. 收口 `requires_visual_context` 的单一计算点并升级 checkpoint/分题契约。
5. 接入 Worker 最终门禁，覆盖重试、断点恢复和旧 checkpoint 拒绝复用。
6. 运行真实 Q8 与普通文字题穿刺；通过后实现历史任务只读审计和替代任务创建。

### 怎么确认做对

- 原坏法：主源缺一个子问、恢复候选更长但漏公式；结果必须失败或定向视觉复核，绝不能生成
  混合题。
- 正常法：真实 Q8 保留页 16–18、`(a)`–`(d)`、14 分和完整分段定义；普通文字题不增加视觉
  调用。
- 边界法：同标签冲突、漏分值、漏图、空 OCR、缺页、重复候选、旧 checkpoint 均有明确且
  可审计的失败结果。
- 迁移法：扫描重复执行结果相同；旧任务保留，新任务通过替代关系可回溯。

## 实现结果

- 分题契约升级为 `paper-question-split-v6`。视觉复核 Markdown 是唯一主源；PDF 文本恢复候选
  只用于发现完全缺失题号，不能覆盖或逐字段补写主源候选。
- 主源题号、子问标签、逐项分值、来源页和视觉依赖由确定性解析器一次提取并对账。时钟页眉、
  带题号子问标题、视觉模型转义换行和 `END OF QUESTIONS` 后的行政页均已纳入边界处理。
- 重叠分题批次只按兼容的结构超集消除重复；同题号不同来源、同标签冲突、题号/子问/分值
  不守恒、无有效主源摘要或视觉判定缺失都会在持久化前 fail closed，不再以字符串长度择优。
- 任务和题目持久化 `source_integrity_status`、分题契约版本、主源摘要、来源种类、来源页和唯一
  `requires_visual_context` 判定；API 同步暴露这些审计字段。
- 迁移把升级前任务保守标记为 `legacy_unverified`。旧任务不能原地重试；替代接口从同一原卷
  创建新任务并双向记录 lineage，删除时保护审计链。历史列表和详情页显示风险、替代入口和
  替代结果。

实现时采用了一个更保守的取舍：主源结构不能证明完整时直接失败，不让恢复文本自动升格；
重新执行任务会复用已有页级视觉结果并重新通过确定性门禁，不增加逐题视觉模型调用。

## 关闭结论

新任务无法再把未证明完整或跨来源拼接的题目送入作答；旧结果不会被静默信任或覆盖，并能从
原卷创建可审计替代任务。真实 Q8 与普通文字题共用同一门禁且端到端通过，本 issue 关闭。
