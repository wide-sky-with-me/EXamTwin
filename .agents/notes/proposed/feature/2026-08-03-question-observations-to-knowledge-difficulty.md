# Agent Note: 题目表现观测映射到知识点并聚合 A/B/C 难度

Status: proposed

## Problem

知识点难度主要是 D 级模型冷启动值。Examiner Report 题目观测已有首批正式数据（数学 1 行、经济 2 行），但没有
映射到 `knowledge_codes`，无法参与知识点难度；报告也只覆盖了极少数场次。难度因此仍不能代表任何真实考生表现。

## Proposal

1. 为已发布的题目观测提供题目到知识编号的候选映射：候选来自该题整卷作答中答案实际引用证据绑定的编号，
   不使用词面匹配。
2. 教师审核映射，追加式保存审核记录；未审核的映射不参与聚合。
3. 新增版本化聚合：知识点难度由 A/B/C 观测与 D 级冷启动按证据强度和版本重新计算，保留每条观测的来源、
   提取版本与聚合版本，D 级历史不被覆盖。
4. 在费用上限与样本质量门禁内分批扩大 Examiner Report 覆盖。

## Alternatives considered

- **由模型直接从报告文本推断知识点** — 覆盖快。模型猜测的映射没有证据绑定，会把题目观测错误归属。
- **用 A/B 观测直接替换 D 级值** — 实现简单。单个观测样本小，替换会丢失历史与来源。

## Acceptance criteria

- 任一聚合难度能列出参与的全部观测、映射审核记录与聚合版本。
- 未审核映射与错科、错场次观测不参与聚合。
- 全量扩展前有明确的费用上限与抽样质量门禁。

## Risks

报告的题号与 Question Paper 规范题号可能不一致，需要进入人工审核而不是正则猜测；扩展覆盖需要付费模型调用。
