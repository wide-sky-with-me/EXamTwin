# Agent Note: 普通测试隔离外部依赖，集成测试只用本次创建的临时数据库

Status: implemented

## Problem

集成测试曾复用固定的 `examtwin_test` 库，旧状态污染结果；单测会自动加载真实 dotenv，可能读取密钥并访问
外部服务；浏览器测试端口被占用时会静默漂移到其他端口，截图基线混用不同平台。

## Decision

- 普通测试（`-m "not integration and not local_assets"`）不自动加载真实 dotenv，逐测试重置配置，并阻止
  外部网络与数据库访问。
- `integration` 测试需显式 `EXAMTWIN_TEST_DATABASE_URL`；测试进程在该服务器上创建唯一命名的临时数据库，
  迁移后运行，结束时只删除自己创建的库。S3 往返测试只写入并删除随机键。
- `local_assets` 标记依赖本机原始资料的测试，默认跳过。
- Playwright 端口必须显式可用，禁止自动漂移；截图基线按平台分目录，不用放宽阈值替代人工对照。
- 测试只保留能拦住独立风险的证据，不断言内部 Factory 身份等实现细节。

## Alternatives considered

- **共享固定测试库** — 启动快。旧数据导致结果依赖执行顺序。
- **端口被占用时自动换端口** — 少一次失败。测试可能连到其他服务而不报错。

## Consequences

- **收益**：普通回归在任何机器上可重复且不泄露密钥；集成测试不触碰开发库。
- **代价与已知上限**：集成测试需要手动提供数据库与 S3；中途被强制终止时临时库可能残留，需要手工删除。
