# Agent Note: 评分准确性用冻结样例评测，作者标签与教师金标准分开报告

Status: implemented

## Problem

模型或供应商升级后，需要可重复的证据说明评分是否仍可信；但手头没有教师双评数据，若把模型自评或作者
预估当成金标准，会高估评分准确性。

## Decision

- `backend/evals/` 保存双科冻结样例（固定 SHA-256）、可重跑的评分脚本、独立整卷盲评脚本与机器可读结果。
- 短答评分经正式 `GradingService` 执行；空白与不可查看图片由规则处理，分别计零与暂缓。
- 运行元数据记录实际模型、推理强度与答案复用来源，避免把恢复实验混作首轮；失败记录保留。
- 作者标签与官方评分示例分开报告；结果不构成真实学生成绩或等级准确率结论。

## Alternatives considered

- **以模型自评或另一模型的判断为金标准** — 可以大规模生成标签。评审模型与被评模型同源，误差相关。

## Consequences

- **收益**：升级前后可在同一组样例上对比。
- **代价与已知上限**：28 例、同源、不含长论述与教师双评；需要真实教师评分后才能声称准确率。评测会调用付费模型。
