# Agent Note: 目标分数策略按正确完成的选定内容计分并冻结执行范围

Status: implemented

## Problem

用户希望模拟“只想拿到某个分数”的作答：在备考时间与考试时间两个预算内选择学什么、答哪些题、答到哪一步。
没有学生画像时，任何对学生实际得分的预测都缺少依据；首轮实验还表明按未校准失误概率折扣分值会严重
低估（经济目标 48、独立盲评 65），论述题部分作答按点估计封顶会高估精度（预计 8（5–11）、盲评 15/20）。

## Decision

- 规划分数指正确完成选定内容时的得分；完整小题使用原题印刷分值（`target-score-v2`）。
- 部分作答必须声明停止边界 `stop_before`；路径总上界不超过目标加容差，推荐方案总下界不低于目标减容差。
- 文字论述类部分作答使用 0 至小题满分的保守区间参与筛选，保留点估计。
- 能力自评只影响学习、练习与作答成本，不折扣分值；不预测学生个人成绩。
- 分析不读取 Mark Scheme、Examiner Report，也不向分析模型提供目标字段。
- 计划在生成答案前持久化，重试复用并核对输入摘要；已完成策略题禁止单题重做；缺停止边界的旧部分方案
  提示新建任务，不静默重规划。
- 最终答案做一次独立范围复核（不提供目标、估分、评分材料与求解轨迹）；违规、不确定、不可用或无检索证据
  时不能完成。普通作答不执行此复核。
- 搜索上限 4096 状态，触顶标为近似。

## Alternatives considered

- **按学生答对概率折扣分值（v1）** — 看似更贴近真实学生。没有校准数据，实验中严重低估；v1 结果保留为
  失败证据。
- **论述题部分作答使用模型点估计封顶** — 区间更窄、方案更“便宜”。少写一个论点不能证明等级分存在固定上限。
- **重试时重新规划** — 能利用新信息。会让已完成的题目与新计划不一致，失去可审计性。
- **声称全局最优** — 结果表述更有力。有限容量搜索不能证明最优或不可达。

## Consequences

- **收益**：计划可审计、可复现，答案不越过选定范围。
- **代价与已知上限**：不能承诺稳定命中目标；外部模型长题超时会让部分方案未执行完整。实际分数仍由评分链路
  形成，计划不是成绩事实源。
