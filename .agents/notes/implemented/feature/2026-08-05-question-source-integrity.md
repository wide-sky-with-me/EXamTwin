# Agent Note: 分题以视觉主源为唯一权威，结构不能证明完整即失败关闭

Status: implemented

## Problem

重叠批次会为同一题产生多个候选。合并器曾按“字段最长”择优，并允许 PDF 文本层恢复候选逐字段补写：
当文本层缺少印刷数学内容时，错误候选反而更长，跨来源拼接出的混合题仍能通过持久化（实测 9660 S2 Q8
少子问、漏分段定义后被持久化）。完整性还依赖模型自报占位词，无法发现模型无声遗漏。

## Decision

- 每物理页的视觉复核 Markdown 是唯一权威主源。持久化题目的顶层题号顺序、子问标签、逐项分值、总分与
  来源页必须与主源逐项守恒，由确定性解析器对账。
- `requires_visual_context` 在对账时计算一次并持久化，后续阶段只消费。
- 同题号候选只在同一主源组内按标签合并可证明互补的部分；冲突时调用一次有界结构化模型选择权威候选，
  结果仍须通过守恒门禁，否则失败。正常无冲突试卷不增加模型调用。
- PDF 文本恢复只定位主源完全缺失的题号，不覆盖、不逐字段补写已有主源题目。
- 任务与题目保存 `source_integrity_status`、分题契约版本与主源摘要；检查点只在契约版本与输入摘要一致时
  复用。
- 未通过当前契约的已结束任务标为 `legacy_unverified`，不原地改写或重试；替代接口从同一原卷新建任务并
  双向记录替代关系。

## Alternatives considered

- **按字段长度择优合并** — 简单，多数情况下长文本更完整。正是它在文本层缺内容时选中了错误候选。
- **用正则修复或判断试卷结构** — 不依赖模型。正则无法可靠识别公式、表格和跨页题结构；正则只用于非结构性
  界面提示。
- **恢复文本自动升格为主源** — 能多救回题目。会把未经原页视觉确认的内容送入作答；实现选择更保守的
  “无法证明即失败”。
- **原地重写历史任务** — 用户无需操作。会抹掉旧结果的审计依据。

## Consequences

- **收益**：进入作答的题目来源单一且结构可证明；历史结果不会被静默信任或覆盖。
- **代价与已知上限**：部分真实试卷会因无法证明完整而失败，需要重试或人工处理；冲突路径增加一次模型调用。
