# Agent Note: 原卷作答 PDF 以图像层叠加已保存答案，位置由人确认

Status: implemented

## Problem

用户需要把系统内的结构化答案写回原卷 PDF 交付或打印，同时不能改动原件、答案或评分记录；原卷的答题
区域形态多样（横线、表格、选项、扫描页），自动定位并非总能可靠。

## Decision

- 导出只复用已保存的正文、公式、图片与图形，不调用模型，不改写原件与记录。
- 后端只读布局接口按物理页识别能归属到题号或子问的横线组，返回原件 SHA-256 与显示坐标；无可靠依据的
  区域不自动定位，由用户框选或输入。
- 用户确认区域后生成实际 PDF 预览再下载；空间不足时原区标 `See PDF p. N` 并追加续答页。
- 新增内容是透明高清图像层；分页只在渲染后的空白行切分，无法切分的连续公式或图形停止导出。
- 生成前校验原件哈希、来源页、越界与重叠、原图冲突、公式溢出、图片加载与空白图形。
- 浏览器端按需加载锁定版本的 `pdf-lib` 与 `html-to-image`；后端不增加浏览器或新云服务。

## Alternatives considered

- **对扫描卷、选项、填空和表格也自动定位** — 用户操作更少。没有可靠依据时会把答案写到错误位置。
- **按可用空间让模型重写答案** — 版面更整齐。会生成与已评审答案不同的新内容。
- **在服务端渲染** — 输出一致性更好。需要后端浏览器运行时，增加镜像体积与攻击面。

## Consequences

- **收益**：原件与答案保持不变；导出失败不会产生被裁剪的答案。
- **代价与已知上限**：新增文字不可选择；位置调整不跨窗口保存；不支持自动圈选选项与逐格填表。
