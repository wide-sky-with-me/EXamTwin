# Agent Note: 难度按证据等级分层，D 级冷启动由模型基于双来源原文直接评级

Status: implemented

## Problem

审计时 183 个学习目标全部只有置信度 0.3 的 D 级冷启动难度，正式难度证据与题目难度均为 0；旧函数用
认知要求替代缺失的历史难度、用课纲复杂度替代 Examiner 严重度，造成重复计权。难度数值没有可追溯来源，
容易被表述为官方结论。

## Decision

- 难度值必须带证据等级与置信度：A 官方量化、B 官方定性、C 有验证的历史估计、D 证据化模型冷启动。
- 知识点 D 级评级只由显式 `knowledge-build` 产生：为每个 Topic / Learning Objective 选取已发布核心库中
  的 syllabus 与授权 textbook 原文，按 Unit 分批让模型在完整目标标尺下直接给出 `[0,1]` 分数、相对位置、
  分项判断与逐字引用。代码只校验结构与双来源引用、按 `0.34 / 0.67` 派生标签，置信度上限 0.45。
- 任一目标缺少双来源证据、引用不能逐字回到输入块或输出不完整时整体不发布；不提供规则回退。
- 题目难度只来自可回到具体题号的官方表现观测：Examiner Report 候选由模型提出，代码校验来源、场次、
  题号、页码、逐字引用与限定词，教师审核后按 run 发布。B 级不换算为伪精确数值。
- A/B/C 观测加入后与 D 级历史一起保留并重新聚合，不覆盖成无出处单值。

## Alternatives considered

- **动作词表与人工权重函数归一化** — 便宜、可重复。它用启发式伪造稳定性，并造成重复计权；新发布路径
  已完全替换它，旧 D 级历史仅保留为证据。
- **从题面长度、模型主观判断或知识点冷启动分反推题目难度** — 能快速得到全量题目难度。没有表现数据支撑，
  会冒充题目观测。
- **把 B 级定性描述映射为固定常数** — 便于聚合。会制造伪精确数值。
- **每个知识点单独调用模型** — 实现直接。成本高，且模型缺少同 Unit 的比较标尺。

## Consequences

- **收益**：每个难度值都能回到文档、页码、块、内容哈希、模型与提示词。
- **代价与已知上限**：D 级仍是模型推断，不是学生表现；全量构建需要付费调用。题目观测到知识点的映射与
  A/B/C 聚合尚未实现，见 [提案](../../proposed/feature/2026-08-03-question-observations-to-knowledge-difficulty.md)。
