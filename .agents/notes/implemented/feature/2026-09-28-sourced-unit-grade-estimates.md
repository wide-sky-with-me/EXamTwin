# Agent Note: 单元等级只按官方分数线精确匹配换算

Status: implemented

## Problem

整卷总览只有数值得分，教师希望看到对应的单元等级。等级换算若使用固定百分比或近似分数线，会给出没有
来源的结论；在评分尚未人工确认时给出等级，也会被误读为正式成绩。

## Decision

- `assessment/grade_boundaries.json` 收录带来源页的官方单元分数线；当前覆盖 2019 年 1 月数学 P1/PSM1、
  2024 年 1 月数学五单元与经济四单元，共 11 组。
- 换算要求科目、年份、考季、Unit、评分规则身份与官方满分完全匹配；任一不匹配、缺少分数线、未评完或存在
  暂缓授分时显示不可估计及原因。
- 待复核得分只产生暂定等级；教师确认或改分后从最终分重新换算。等级换算不修改数值评分。
- 展示官方来源与距上一等级的分差；不输出单卷 A* 或完整 AS/A-level 资格等级，不把模型置信度解释为
  达标概率。

## Alternatives considered

- **按固定百分比推算等级** — 覆盖所有试卷。不同场次分数线不同，结果没有来源。
- **使用相邻场次或近似满分的分数线** — 覆盖更多试卷。错配会给出看似精确的错误等级。

## Consequences

- **收益**：每个等级都能回到官方来源，暂定与确认状态清楚区分。
- **代价与已知上限**：只有已收录分数线的场次能显示等级；新增场次需人工录入并核对来源。
